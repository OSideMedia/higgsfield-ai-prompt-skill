# Higgsfield Acting Director — withdrawn

This sub-skill carried a character-performance system adapted from third-party acting-direction
skill files, which the earlier version of this file credited to the "Hell Grind" brief. It was withdrawn from the current tree in November 2026 because O-Side Media does not
hold, and could not confirm, the right to redistribute that material. See `THIRD_PARTY_NOTICES.md` at the repository root.

Other files in this repository still point here by section name. Those pointers are historical:
the sections they name are no longer in this repository, and nothing replaces them here.
